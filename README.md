## 公開までにやること

### 1. プレースホルダを埋める

HTML 内に `{{ }}` の形で残しています。**全て埋めるまで公開しないでください。**

```sh
grep -rno '{{[^}]*}}' index.html legal/index.html privacy/index.html | sort -u -t: -k3
```

現在、未入力のプレースホルダはありません（上の grep で 0 件になることを確認する）。

Google フォームの項目は4つ（保護者氏名 / メールアドレス / お子様の学年 / 現在の学習状況）。変えたら LP の申し込み欄とプライバシーポリシーの記載も合わせる。成績や志望校は相談時に聞く。

### 2. 画像を置く

- `assets/img/ogp.jpg` — 配置済み（サービス名・見出し・名前・料金・顔写真）。見出しや料金を変えたら作り直す。
- 保護者様・生徒さんからの声（手紙・色紙の引きの写真）— `assets/img/voice-1.jpg` などに置き、`index.html` の「講師について」内のコメント（`.voices`）を外す。名前・学校名・地域が写り込まないものにする。CSS は用意済み。

### 3. URL を確認する

独自ドメインを設定する場合、`canonical` と `og:url` / `og:image` / `twitter:image` の絶対 URL（現在は `https://ah24ok2-svg.github.io/online-katekyo-kida-lp/`）を書き換える。サイト内のリンクは全て相対パスなので、そちらの変更は不要。

### 4. 特商法表記を確認する

記載内容は事業形態により異なります。個人事業で役務を継続提供し対価を受け取る場合、氏名・所在地・連絡先・料金・支払時期・解約条件などの表示が求められるのが一般的ですが、**最終的な記載内容は本人が確認すること。**

### 5. 自己紹介動画（後日）

`index.html` の「講師について」内に、60〜90秒の自己紹介動画を入れる枠をコメントで残してあります。撮影後、コメントを外して `iframe` の `src` を入れる。CSS（`.video`）は用意済み。

### 6. 原稿待ちの項目（2026年10月のフィードバックより）

本人の原稿・素材が必要なため、まだ入れていないもの。

- 個人で始めた理由（200〜300字）— 「講師について」内にコメントで枠あり
- 塾講師時代の生徒1人の話（学年・最初の状態・何を変えて何が変わったか。学校名・地域は出さない）
- 成績が上がった例・進学先（出せる範囲で）
- 授業画面の写真1枚（iPad で写真に書き込んでいる画面など）
- Google フォーム側：項目名「保護者指名」→「保護者氏名」の修正、フォーム上部に LP と同じサービス名と説明文（「中学生のオンライン家庭教師（マンツーマン・全5科目）の無料相談」など）を1行入れる

## 書くときの原則（編集時も維持する）

- 断定表現を使わない（「必ず」「絶対に」）
- 緊急性を煽らない（「今だけ」「残りわずか」）
- 実績は数字で書くが、盛らない。「（非常勤時代含む）」は実績欄の1か所だけに書く
- 軸はマンツーマン（1対1）。送迎不要・低価格は後押しとして添える
- 塾を否定しない。集団塾が合う子もいる、という書き方にする
- 「伴走」「落とし込む」などのビジネス文書の言葉や、浮いた比喩は使わない
- 価格は通常価格との二重表示（「通常◯円→今だけ◯円」）をしない。将来の値上げ予告・料金据え置きの約束も書かない
- 生徒の個別事例に、学校名・地域・部活・家族構成を出さない
- マナリンク、および AI 事業（`new-portfolio.kentaro`）への言及・リンクは置かない
- CTA はヒーロー・講師紹介のあと・料金のあと・最終セクションの4箇所。ボタンの近くに「オンライン個別指導の、30分の無料相談」と添える
- 朱（`--vermil`）は CTA ボタンと、強調（`.em`：朱の文字色＋太字）、料金の3つの強みの枠、授業のやり方の図の書き込み（`.s-mark`）にだけ使う。下線での強調はしない。強調するのは「マンツーマン」「2,000円〜」「入会金0円」「無料相談」など伝えたい言葉に絞る
